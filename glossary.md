# Glossary

| Term | Meaning |
|------|---------|
| **AD1** | AccessData logical evidence image format, read with FTK Imager |
| **Amcache** | Registry hive recording program paths, SHA1 hashes and first-seen times |
| **BAM / DAM** | Background / Desktop Activity Moderator: per-user last-execution times in the SYSTEM hive |
| **CLSID** | Class ID, the GUID that identifies a COM class in the registry |
| **DFIR** | Digital Forensics and Incident Response |
| **DiE** | Detect It Easy: identifies compilers, packers and file types |
| **DMA** | Direct Memory Access; PCIe devices that read or write RAM without the CPU |
| **E01** | EnCase / Expert Witness disk image format |
| **EVTX** | Windows Event Log file format |
| **IOC** | Indicator of Compromise: a hash, IP, domain, path, etc. |
| **IOMMU** | Hardware unit that restricts which memory a device may access with DMA |
| **LOLBin** | Living-off-the-land binary: a legitimate system tool that can be abused |
| **MACB** | Modified, Accessed, Changed (metadata), Born (created) timestamps |
| **MFT** | Master File Table: the NTFS index of every file |
| **MISP** | Open-source threat-intelligence sharing platform |
| **MZ** | The first two bytes of every Windows PE file (DOS header magic) |
| **PDB** | Program database (debug symbols); its path often leaks the developer's project name |
| **PE** | Portable Executable, the Windows format for .exe and .dll files |
| **Prefetch** | `.pf` files that speed up app launches; also a strong record of execution |
| **ShimCache** | AppCompatCache: evidence a file existed (not proof it ran on Win10+) |
| **SRUM** | System Resource Usage Monitor: per-app CPU and network history |
| **SS / screenshare** | Live PC check in game communities to look for cheats |
| **STIX** | Structured Threat Information Expression (the OpenCTI data model) |
| **Sysmon** | Sysinternals service that logs process, network and file events |
| **Timestomping** | Changing file timestamps to mislead a timeline |
| **UserAssist** | ROT13-encoded registry record of GUI program launches |
| **VSS** | Volume Shadow Copy Service snapshots |
| **YARA** | Pattern-matching rule language for identifying malware |
