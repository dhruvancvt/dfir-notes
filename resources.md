# Resources

## References
- [MITRE ATT&CK](https://attack.mitre.org/): adversary technique knowledge base
- [LOLBAS](https://lolbas-project.github.io/): Windows binaries that can be abused
- [SANS DFIR posters](https://www.sans.org/posters/): Windows forensic analysis and hunt-evil cheat sheets
- [The DFIR Report](https://thedfirreport.com/): real intrusion write-ups
- [Awesome Incident Response](https://github.com/meirwah/awesome-incident-response)
- [Awesome Forensics](https://github.com/cugu/awesome-forensics)
